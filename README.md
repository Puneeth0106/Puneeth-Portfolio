# Puneeth Kumar Amudala — Personal Portfolio

Live at **[puneethamudala.com](https://puneethamudala.com)**

A personal portfolio built with Angular, showcasing my work as a Generative AI Engineer.

## Sections

- **Home** — Introduction and resume
- **About** — Bio, skills, and education
- **Portfolio** — Featured projects
- **Training** — Certifications and courses
- **Achievements** — Awards and credentials
- **Contact** — Get in touch

## Tech Stack

- Angular 15 + TypeScript
- GitHub Pages (custom domain via Namecheap)
- PWA with Angular Service Worker
- particles.js, vanilla-tilt.js, wow.js

## Run Locally

```bash
npm install -f
ng serve
```

Open [http://localhost:4200](http://localhost:4200)

## Deploy

```bash
ng deploy --base-href="/"
```

## Customization

All content (projects, bio, skills, links) lives in a single file:

```
src/assets/data.min.js
```

Edit that file to update any section — no component changes needed.
